# 0001 — Rename campus entities to Vibe-domain names

We chose to rename all BBS-prefixed entities (BbsPost → VibePost, BbsCategory → Channel, BbsComment → VibeComment) throughout the entire codebase — Java classes, DB tables, Mapper XML, controllers, and frontend — rather than keeping the old names and only changing the business meaning. The alternative (keep class names, change only content/UI) would have been cheaper but would create a permanent disconnect between code vocabulary and domain language, confusing future contributors and making the documented domain language impossible to speak while reading the code. The rename touches many files but is a one-time mechanical cost; the ongoing cognitive benefit of aligned naming outweighs it.

# 产品提案：评审现场化社区（Review-in-Public）

日期：2026-11-15 · 状态：**提案，待用户定稿**
来源：2026-11-15 定位访谈。用户判断：现有设计是"跟过往论坛一模一样的换壳项目"，缺少只有这里有的东西；定位选择"招牌功能优先"，四个创新主轴全选。

## 一句话

**把 GitHub Actions 的公开性搬到社区问答上：每个提问都走一条社区围观得到的公开评审流水线，AI 以公民身份参与，社区与 AI 共同裁定"解决"，解决过的提问沉淀为知识库——声誉就是沉淀下来的证据。**

四个主轴不是四个功能，是同一条帖子的生命周期在四个面上的呈现：

```
发帖 → [AI 评审现场] → [AI+社区共裁] → [解决闭环] → [知识沉淀]
         围观             常驻公民        闭环状态      证据档案
```

- **AI 评审现场化**：评审过程的每一步公开可见、可围观、可回放
- **AI 常驻公民**：AI 在生命周期各环节主动参与，其发言可追溯、可评价
- **问题解决闭环**：生命周期有终点——"已解决"由 AI 结论与社区确认共同裁定
- **证据档案声誉**：生命周期全部产物自动累积为用户档案——声誉不是积分，是证据

## 与现有资产的对接（不是从零开始）

| 已有 | 变成什么 |
| --- | --- |
| 评审管线（租约/fail-closed/重试，ADR-0005/0012/0014） | 现场化的事件源：管线已有真实状态机，缺的只是把状态变化广播出去 |
| `ai_review_log`（966 条真实日志） | 评审回放墙 + 声誉档案的数据底座，已在库 |
| Agent Mention（ADR-0018，召唤/冷却/占位重试） | AI 公民的交互原语：从"@才答"升级为"debug 频道自动抢答"，冷却与租约机制复用 |
| 评论情感列（0008/0009 刚上线的 sentiment） | 社区对 AI 结论"认同/质疑"投票的现成存储起点 |
| Profile Workspace（stat strip/activity） | 证据档案的骨架：六格统计升级为评分曲线 + 被采纳建议 + 解决他人问题数 |
| ES + ADR-0011 的搜索语义 | 知识库的近邻推荐（ES 修复后）；不依赖 ES 也有降级路径 |

## 功能切片（按依赖排序，每片独立可验收）

**S1 评审现场（围观）**
帖子详情页的评审盒从"四步假想轮播"升级为真实进度：管线各阶段（领取→评审→校验→回帖）状态广播（轮询 `agent-logs` 即可起步，SSE 是升级项），围观者看到的是真实管线而不是动画。复用 replay 语义；ADR-0010 的"永不读作实时声称"规则演化为"只有真实是实时，其余一律标注 replay"。

**S2 共裁与闭环**
AI 结论可被社区"认同/质疑"（复用 sentiment 列），提问可被作者标记"已解决"（AI 评分 + 社区确认合成闭环状态，规则写死在服务端）。闭环状态是 schema 变更（vibe_post 加列），走迁移演练。

**S3 AI 常驻公民**
debug 频道新帖无人应答时 AI 自动抢答（复用 Mention 的占位/冷却/租约；触发规则独立成 ReviewPolicy 的并列实现）；AI 的历史发言聚合页：它评过什么、被认同多少、被质疑多少——AI 也有档案。

**S4 证据档案**
个人主页六格统计升级：AI 评分曲线（历史评审）、被采纳建议数、解决他人问题数、共裁参与度。数据全部来自既有表，无新采集。

**S5 知识库**
已解决帖子的结构化沉淀视图 + 语义近邻推荐（"提问前先看相似问题"）。ES 不可用时按标签/频道降级（ADR-0011 语义延续）。

## 诚实约束（这个项目自己的纪律）

- ADR-0009 说"范围在部署处完成，再动必须论证"——本提案就是那个论证；若采纳，开一轮新 ADR（编号 0022）显式重开范围。
- S2 需要 schema 变更（走迁移演练链路）；S1 的真实进度广播需要管线打点（ADR-0014 的 defer-publisher 缝正好是落点）；S3/S4 不动 schema。
- 四片没有一片需要推翻验收链路——全部按"契约冻结 → 独立实现 → 独立 Verifier"走。
- 冷启动诚实说：真实社区需要人；招牌功能先让作品集有辨识度，这是选"招牌功能优先"的本意。

## 与设计改造轮的关系

forge 设计轮（shell/token/i18n/密度）是**地基，不因本提案作废**——招牌功能的每一个面都长在新骨架上（现场化改帖子详情页、共裁改列表行状态、S3 改 AI 发言聚合页、S4 改个人主页）。顺序：**设计轮冻结开工（地基）→ 本提案定稿 → to-spec/to-tickets 拆片**。设计轮契约的骨架决策不受影响；个人主页验收条留出证据档案的挂载点。

# Nexus-Vibe 定位与呈现计划（方向 A · 面试作品）

> 立项：2026-09-16 ｜ 状态：待执行
> 决策来源：四个方向（A 面试作品 / B 小规模真实使用 / C 开源基建 / D 归档封版）对比后选定 A。
> 本文件的作用：给出一个**可判定**的"做完"定义，替代此前"这个项目要做成什么"长期没有答案的状态。

## 为什么需要这份文件

项目在工程层的自我描述是完整的（`docs/adr/` ×10、`docs/research/` ×10、`docs/tickets/` ×4），
但缺少一个被承认的**意图层**：`CONTEXT.md:3` 写的是品类（"一个 Vibe Coding & AI 开发者交流论坛"），
而不是定位；唯一写准了定位的那份文档（`Nexus-Vibe-项目全量梳理.md`）被 `.gitignore:66-68`
明确排除，注释理由是 "a write-up **about** the project rather than **of** it … Never add it back."

结论：仓库有完整的"怎么做"与"技术层为什么这么做"，没有被承认的"为了什么"。
本计划的第一项就是把这个缺口补上，它零成本且决定后续所有取舍。

## 定位声明（候选，待确认）

**一句话**：

> 不是"接了 LLM 的论坛"，而是"把 LLM 当成一个会宕机、会吐脏数据、会被注入的不可靠组件来治理"的全栈系统。

（此句出自 `Nexus-Vibe-项目全量梳理.md` 第 12 行，是全项目最准的一句定位。原文在仓库外，本计划把它的**结论**带回仓库。）

**统一主题**（用于串起所有对外叙事）：不接受无法核验的说法。
在项目里的五处同源表现：评分必须可解释且旧评论被取代而非并存 · `never fall back to fabricated summary`
· R2 让"200 夹带 401"不可表达 · E9 修"报告的数值不是测量" · E10 修"从未画出来的面板"。

## 完成线（Definition of Done）

方向 A 的 KPI **不是用户数**，而是：一个没看过本项目的人，在 5 分钟内能自己说出这个项目"不是论坛，是什么"，并且愿意继续追问。

因此以下六项全部达成，才算做完：

| # | 判定标准 | 现状 |
|---|---|---|
| A1 | `CONTEXT.md` 的首段从品类描述改为定位声明；README 首屏出现同一句定位 | 未做 |
| A2 | 存在一份"阅读路径"文档，提供 30 秒 / 10 分钟 / 90 分钟三档入口 | 未做 |
| A3 | 存在一份证据索引：每个对外主张对应一条可复现命令或一个 `file:line` | 部分（README 已链 6 篇，缺统一索引） |
| A4 | **落地页**：无需登录即可看到一份真实的 AI 评审档案（含 score / severity / verdict / 三维发现） | 未做（`frontend/src/pages/` 17 个页面全部为应用内页面） |
| A5 | 3–5 个真人完成"注册 → 发一篇带代码块的帖 → 读到 AI 评审"，并记录其原话 | 未做 |
| A6 | 一次真实公网部署，落地页与 A4 的示例在公网可访问 | 部署路径有（Cloudflare Tunnel），未按本方向验收 |

**A4 的准确表述**（修正 2026-09-15 的一处误判）：`/post/:id` 在 `App.tsx:83` **不在** `AuthGuard` 内，
所以帖子详情页本来就是公开的。真正的障碍不是登录，而是**没有一份被策展的示例**——
AI 评审只对带代码块的帖子触发，而生产部署 `DEMO_SEED_ENABLED=false`，首页从零开始。
结果：全项目最有说服力的产物，访客看不到。

**A5 的性质说明**：它不是"做社区"，不做运营、不做增长。它只要求找 3–5 个真人各用一次，
把"我构建了"升级为"它被使用了，这是数据"。成本远低于方向 B 的完整形态。

## 执行顺序与理由

1. **A1 定位句** —— 零成本，且它决定后面所有呈现的取舍。先做。
2. **A2 阅读路径** —— 筛简历的人只给 30 秒；没有这一档，后面做得再好也到不了第二轮。
3. **A3 证据索引** —— 让过了 30 秒的人有东西可查，把"愿意追问"变成"追得到"。
4. **A4 落地页 + 免登录示例档案** —— 最贵的一项，且必须等 A1 定了口径再做。
5. **A5 真人实证** —— **与 A4 并行启动，不排在最后**。它需要时间发酵（发帖、回访），
   放在末尾就会变成"最后一周找人凑数"，那样拿到的不是证据。
6. **A6 公网部署** —— 收尾，同时是 A4/A5 的载体。

## 明确不做（Non-goals）

- 不做社区运营、不做增长、不追用户规模（那是方向 B）
- 不新增功能，除非该功能直接服务于呈现
- 不做方向 C 的开源发版；只借它一个动作——把"AI 评审失败治理"抽成一条可独立阅读的代码路径 + 一页说明
- 不为了"看起来更完整"而补无关功能

## 验收方式

- **A1/A2/A3**：由一份没有上下文的人（同学即可）在不提示的情况下阅读，记录其是否能复述定位、是否找到证据。
- **A4**：不登录、清空 localStorage，直接打开落地页；要求看到真实评审数据而非占位文案。
- **A5**：保留参与者的原始反馈文本，不转述、不修饰；若只有 2 人完成，就写 2 人。
- **A6**：公网 URL 抽查 `GET /actuator/health` 与落地页，两端均须正常。落地页本身沿用 2026-09-15
  的信息架构对照结论（炉子七槽位 → 本项目资产），其中 `docs/assets/gui-test-screenshots/` ×8 为现成可用素材。

## 已知的自我拆台风险（写下来以免重犯）

本项目的纪律是"不接受无法核验的说法"。方向 A 需要大量**对外主张**，而这些主张天生无法被代码验证。
处理方式：不弱化纪律，而是让每条主张**附上复现路径**——主张可以主观，证据必须可执行。
凡是拿不出复现路径的主张，就不写进对外材料。

## 下一轮待办清单在方向 A 下的取舍（2026-09-16 补）

对象：`docs/tickets/next-cycle-backlog.md`（PR #5 草稿，分支 `codex/next-cycle-backlog`），共 8 张票。

判定标准只有一条：**这张票能不能变成面试官看得见的东西，或者它是不是 A4 / A5 / A6 的前置条件。**

| 票 | 判定 | 理由 |
|---|---|---|
| OPS-1 飞书告警真实送达 | **做** | A4/A5/A6 的前置——没有公网地址落地页无处落脚。它把 bridge 从"签名正确"推进到"有人真的收到"，是"主张 → 可核验证据"的直接样本；且自带反向验证（故意配错 secret，确认桥报出拒绝而非吞掉），这在作品集里比正向验证更值钱 |
| OPS-2 Cloudflare Tunnel 与公网地址 | **做** | A6 本体。与 OPS-1 同为整张清单里仅有的两个外部凭据阻塞项 |
| OPS-3 告警与回滚进 CI | **做（小）** | "门禁必须可信"主题的延伸，且是可展示的工程判断；排在 OPS-1/2 之后 |
| FE-1 前端崩溃上报 | **可做** | 与 2026-09-15 前端设计审计独立命中的同一处（`ErrorBoundary` 缺 `componentDidCatch`）。注意 FE-1 只覆盖"上报"，不覆盖"边界只有一层且在路由之上"，那一条仍需单独处理 |
| SEARCH-1 ES 对账策略 | **只做决定** | 票据自述 "it is a decision before it is code"。写一篇 ADR 成本极低，而"在两方案里选了哪个、为什么、否决了什么"正是面试里最有说服力的材料；实现可延后 |
| SEC-1 集中式鉴权 | 暂缓 | 纯内部质量，不产生可展示证据 |
| DB-1 Flyway 版本化迁移 | 暂缓 | 同上，且与 E5 恢复演练绑定，单独做价值有限 |
| REL-1 非 root web 容器 | 暂缓 | 同上；票据已自述值得单独一轮带验证的改动 |

**结论**：8 张票里，方向 A 需要 3 张（OPS-1/2/3）、可选 1 张（FE-1）、只做决定 1 张（SEARCH-1）、暂缓 3 张。

**OPS-1 的成本澄清**：阻塞项是一个飞书群自定义机器人（自建群 → 添加机器人 → 复制 webhook），约五分钟，免费。
票据 **Rejected** 段拒绝的"用内网 webhook sink 代替"在方向 A 下**同样应该拒绝**——因为这里唯一的价值就是"真实送达"，
内网 sink 证明的是演练已经证过的签名正确性。
